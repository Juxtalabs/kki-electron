that the system will recognize a person without knowing their identity in the database. This method is superior in user-friendliness because it doesn't need other authentication. � Face Identification The user�s face image is registered into a database (FaceGalleries), contains the user's data from the same group/organization/etc. The system will be able to recognize the user faces after the registration process is completed. � � � Face Verification This is 1:1 authentication means that the system ensures the person is actually who claims the identity. This method is more accurate and secure than Face Identification but inferior in user-friendliness due to needing for other authentication like RFID, NFC, KTP, or printed QRCode. � User register by taking a frontal picture of their face and adding a unique identifier such as citizen ID or employee ID to the system. After the registration is completed, the system can verify whether the ID belongs to the correct user. � � Reference Image Requirements To provide more accuracy and precision of facial comparison results, we recommend that you use the following guidelines when choosing reference photos for registration. &#9679; Use an image of a face with a straight-on camera. &#9679; Use an image of a face with both eyes open and visible. &#9679; The image should contain the full head and shoulders of the person. &#9679; Avoid items that block the face, such as masks, headbands. &#9679; Use color images. &#9679; Use images of faces with neutral facial expressions with mouth closed and little to no smile. &#9679; Use images with flat lighting on the face. &#9679; Use images that are bright and sharp. &#9679; Use images that have sufficient contrast with the background. A high-contrast monochrome background works well. &#9679; The minimum face resolution is 150 x 150 pixels. Higher-resolution images require a larger minimum face size. &#9679; Format image: JPG (JPEG) and PNG. � Recommended Reference Image � Unrecommended Reference Image � Image Recommendations � Device Set-Up Requirements Constraints There are several constraints set in order to obtain an optimal performance: &#9679; The camera is placed in a hallway with a� minimum length of 3 meters. &#9679; Users are not allowed to wear face attributes other than eyeglasses or a mask. &#9679; If there is a recognition failure when the user is wearing glasses or a mask, the user is expected to take off the glasses or mask in order to provide more features for recognition. &#9679; Users� faces need to be evenly illuminated. &#9679; Users need to walk at an average walking pace. Image/Camera Set-Up &#9679; The face resolution must be at least 125 x 125 pixels. For example, if you have a 360p camera resolution, the distance camera to people should be less than 45 cm. &#9679; Image size should be no larger than 500KiB. This is to ensure the best possible latency for sending the image request through the network. Higher sized images will yield slower latency. &#9679; Point the camera to a good lighting environment, not too dark or bright and with no backlight. &#9679; Camera height should be between 1.5 m - 1.75 m. &#9679; If video camera based, frame rate, the recommended frame rate is 30 fps. (at least 25 fps) &#9679; Encoder Bitrate, the recommended encoder bitrate is 3 Mbps. &#9679; Codec, the codec should be h.264 or h.265. &#9679; Give a marker place approximately less than 3 m from the camera to take pictures. � � Marker Example Trigger Some ideas that can be used to trigger photo submissions to the API: &#9679; Printed QR Code &#9679; RFID &#9679; NFC &#9679; Ultrasonic Module &#9679; Infrared Module &#9679; Face location and minimal size � � API Documentation � Base URL https://api.riset.ai/face Postman Collection � API Endpoints � Example URL for Facegallery Endpoints: https://api.riset.ai/face/facegallery/my-facegalleries � GET /facegallery/my-facegalleries This API gives the list of facegallery.
